# DishCare AI Technical Troubleshooting

## No Signal

If the television displays No Signal:

1. Check that the television is using the correct HDMI input.
2. Verify that the set-top box is powered on.
3. Check that the accessible HDMI and signal cables are secure.
4. Restart the set-top box by disconnecting power for 30 seconds.
5. Wait for the device to restart.

If the issue persists, create a technical complaint or offer
a technician visit.

Customers must not climb onto rooftops or adjust outdoor
dish equipment themselves.

## Black Screen

Confirm that the television and set-top box are powered on.

Verify the selected input source.

Check whether the issue affects every channel or a single channel.

If only one channel is affected, verify that the channel
is included in the subscription.

## Poor Picture Quality

Check the HDMI connection and television resolution settings.

If multiple channels are affected after restart,
offer technical assistance.

## Error E16 - Demo Error Code

This demonstration error indicates that the requested channel
is not currently authorized.

Check subscription status and channel membership before
recommending payment or technical troubleshooting.

## Error E48 - Demo Error Code

This demonstration error represents a signal reception issue.

Follow the No Signal troubleshooting procedure.

Escalate persistent signal issues to a technician.
